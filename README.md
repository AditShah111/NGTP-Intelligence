# NGTP Litigation Readiness & Viability Engine

> Expert Indian Tax Litigation Analysis Platform for SCNs, DRC-01/07, First Appeals, Section 16(2)(c), Section 16C, Section 74, and Supreme Court Precedent Strategy.

Built using **Anthropic GAN-Inspired Harness Engineering** and **OpenAI Codex Repository Architecture** principles.

---

## 🏛️ System Features

1. **13-Step Statutory & Evidentiary Analytical Pipeline**:
   - **Step 1**: Case Fact Matrix (Traceable to documents, page/paragraphs, OCR status)
   - **Step 2**: Statutory Parameter Tests (Section 16(2)(a)-(c), 16(2)(aa), 16(4), 16(5)/16(6), 17(5), 73/74, 155)
   - **Steps 3 & 4**: Landmark Judicial Precedent Comparability Scoring (0–100) (*Suncraft Energy*, *D.Y. Beathel*, *Arise India*, *LGW Industries*)
   - **Step 5**: Lower Authority Error & Jurisdictional Defect Matrix
   - **Step 6**: Syllogistic Submission Optimizer (**Fact → Evidence → Statute → Precedent → Rebuttal**)
   - **Step 7**: Adversarial Red-Team Stress Testing (Revenue Departmental Representative Attack Simulation)
   - **Step 8**: Evidence Gap Prioritization & Remediation Matrix
   - **Steps 9 & 10**: Dual Radial Scoring (Litigation Readiness vs Substantive Merits Viability)
   - **Step 11**: Score Remediation Roadmap (Base Score → 100 Potential Score)
   - **Step 12**: Pleading & Prayer Defect Audit
   - **Step 13**: 11-Part Final Evaluator Verdict & P0/P1/P2 Action Plan

2. **Supabase PostgreSQL Persistence (Isolated `ngtp` Schema)**:
   - Dedicated schema guarantees zero collision with existing tables (`public.society`, etc.).
